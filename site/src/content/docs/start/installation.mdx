No runtime dependencies. TypeScript types are included.

## Runtimes

| Runtime | Support |
|---|---|
| Node.js | ≥ 20.16 (`engines` field) |
| Bun, Deno | Supported |
| Cloudflare Workers | Supported. Enable `nodejs_compat` for [deadline propagation](/concepts/context-and-signals/) |
| Browsers | Supported, with two features degraded (see [Runtimes](/concepts/runtimes/)) |

## ESM and CommonJS

Both builds ship with their own type declarations, resolved through `exports`:

<Tabs syncKey="module">
  <TabItem label="ESM">
    ```ts
    import { ResiliencePipelineBuilder } from '@nodelibraries/resilience';
    ```
  </TabItem>
  <TabItem label="CommonJS">
    ```js
    const { ResiliencePipelineBuilder } = require('@nodelibraries/resilience');
    ```
  </TabItem>
</Tabs>

The package is marked `"sideEffects": false`, so bundlers drop every strategy you don't import. See
[Bundle size](/concepts/bundle-size/).

## Entry points

Integrations live in subpaths, so the main entry never pulls in framework code.

| Import | Contents |
|---|---|
| `@nodelibraries/resilience` | Builders, every strategy, outcomes, errors, registry, telemetry, batches, `createStats` |
| `@nodelibraries/resilience/outcome` | `Outcome` helpers and error classes only, for code that just handles results |
| `@nodelibraries/resilience/testing` | `FakeTimeProvider` |

| `@nodelibraries/resilience/axios` | [`attachResilience()`](/integrations/axios/) |

## Optional peer dependencies

Install these only for the subpath that needs them. They are marked optional, so package managers don't
install or warn about them otherwise.

| Peer | Version | Used by |
|---|---|---|
| `@nestjs/common`, `@nestjs/core` | ≥ 10 | `/nestjs` |
| `@opentelemetry/api` | ^1.4.0 | `/otel` |
| `prom-client` | ≥ 14 | `/prometheus` |
| `axios` | ≥ 1.0.0 | `/axios` |
| `fastify` | ≥ 4 | `/fastify` |
| `koa` | ≥ 2 | `/koa` |

`/redis` and `/adapters` don't declare peers: you pass in a client or store you already created (ioredis,
node-redis, rate-limiter-flexible).

## CDN (script tag)

A minified IIFE build of the main entry is published at `dist/browser/resilience.min.js`. It exposes
`window.resilience`:

```html
<script src="https://unpkg.com/@nodelibraries/resilience"></script>
<script>
  const { retry } = window.resilience;
  retry(() => fetch('/api/health'), { maxRetryAttempts: 3, delay: 500 }).then(console.log);
</script>
```

`https://cdn.jsdelivr.net/npm/@nodelibraries/resilience` serves the same file.

<Aside type="caution">
The script-tag build contains only the main entry. Subpaths such as `/fetch` or `/testing` need a bundler or an
ESM CDN.
</Aside>
